# sb3forge v0.4.0 UI

日本語の説明文から近いサンプルを検索し、DSLを編集して Scratch 3 の `.sb3` を構築するブラウザーUIです。

## 起動

Node.js 20 以上が必要です。

```bash
npm start
```

表示されたURL（通常は http://localhost:4173）をブラウザーで開いてください。起動時に `core-source/` 内の圧縮ソースから `sb3core.mjs` を復元します。

## データセット

学習データはこのUIコードのコミットには含めていません。データセットを同じディレクトリの `dataset_basic_v1/tasks.jsonl` に置けば自動で読み込まれます。配置しない場合は、UIに表示される「tasks.jsonl を選択」から元の v0.4.0 ZIP に含まれるファイルを選んでください。データはブラウザー内で読み込みます。

## 動作確認

```bash
npm run test:smoke
```

## 重要な制約

v0.4.0 は学習済みLLMではなく、基礎データの近傍検索と数値差し替えによるベースライン生成です。DSLの解析、SB3の構築、構造検証が成功しても、Scratch/TurboWarpでの実行結果まで保証するものではありません。
